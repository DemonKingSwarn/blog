# 1. Languages

## The Language (Jai)

For those who don't know, Jai is a systems language developed by Jonathan Blow majorly for game development because he was frustrated by C++ and it's unergonomic ways. Ever since I got into it's closed beta, I haven't touched any C or C++ code at all.

I like it for a couple of reasons:

- It is fun to use, and still does manual memory management unlike some other languages. (looking at you rust).
- It is one of the most human effort driven language right now, without any LLM in the project.
- The meta-programming is really convenient to have.

Also technically, it doesn't have any name yet and Jon calls it "The Language".

## Odin

It is a lot similar to Jai (minus the meta-programming aspect of it, and the fact that we dont have to use semi-colons). Other than that, all the stuffs applied to Jai applies here.

# 2. Game Development

## Godot

It is by far the best open-source game engine out there, even better than Unity. Most people have no idea that the 3D games in Godot can reach Unreal level of fidelity without any performance loss. 

Here are few things I love about it:

- It's node based structure is just so easy to understand.
- You can make any type of thing in it just by using Godot-driven development (using only the aspects of Godot, without touching any code).
- Every new version improves it a lot more.

## Raylib

- It is my favourite game framework out there, and works on every single platform you can imagine.
- I love that all the documentation for it is just a single cheatsheet file, just like old times.a
